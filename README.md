## Features
- **8 curated themes** — Cyberpunk, Mythic, Cosmic, Nature, Vintage, Gamer, Aesthetic, Minimal
- **3 length modes** — Short (1 word), Medium (2 words), Long (2 words + number)
- **4 case styles** — `lowercase`, `Capitalize`, `PascalCase`, `snake_case`
- **Number toggle** — append a random 1–99 digit when you want it
- **8 nicknames per batch** — instantly regenerate with one click
- **Favorites** — heart any nickname to save it, persisted in `localStorage`
- **Copy to clipboard** — one-tap copy on every result
- **Hand-curated word pools** — each theme has 30+ vetted words, no random gibberish
- Fully responsive
- Full keyboard accessibility (focus rings, `aria-*` labels)
- No authentication
- No tracking
- No ads

## Tech Stack
- React 19 (Vite 5)
- CSS custom properties (Apple-inspired dark UI, no framework)
- `localStorage` for favorites
- Vercel-ready static deploy

---

## How It Works
1. Pick a theme from the grid
2. Adjust length, case style, and the numbers toggle
3. Click **Generate** for a fresh batch of 8 nicknames
4. Heart the ones you like — they save to your favorites
5. Copy any nickname to clipboard with one tap

> Generation runs entirely in your browser. No data leaves your machine.
